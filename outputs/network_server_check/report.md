# 三个网络的服务器测试结果

测试日期：2026-10-14（北京时间）。

已通过指定跳板机连接目标服务器。三个文件位于 `/data/lym/`，SHA-256 与桌面上的原文件一致。测试没有修改服务器上的网络文件。

结论：三个文件均定义用于整段一维序列分类的网络，使用 Conv1d，而不是 Conv2d。输入为 `[批量大小, 通道数, 序列长度]`，分类输出为 `[批量大小, 类别数]`。它们可处理 CF/PW/PRI 三通道时间序列，也可用于其他一维信号分类。

## 实测环境与结果

- Python：`/data/lym/anaconda3/envs/radar/bin/python`。
- PyTorch：2.1.0；测试在 CPU 上进行，2 个计算线程。
- 模拟输入：批量大小 2、通道数 3、类别数 11。
- 训练检查：交叉熵损失、反向传播、梯度有限性，以及一次 SGD 参数更新。

| 模型 | 长度 128 | 长度 512 | 长度 3000 | 一次训练更新 |
|---|---|---|---|---|
| ResNet18 | 通过 | 通过 | 通过 | 通过，长度 512 |
| ResNet50 | 通过 | 失败，注意力位置编码尺寸不匹配 | 未测 | 通过，长度 128 |
| CNN | 失败，卷积核大于剩余序列长度 | 失败，卷积核大于剩余序列长度 | 通过 | 通过，长度 3000 |
| EfficientNetB0 | 通过 | 通过 | 通过 | 通过，长度 512 |

所有成功的前向测试均输出有限的 `[2, 11]` 分类分数。所有训练步骤均具有有限梯度，第一层参数成功更新。

## 使用限制

1. **CNN 限制序列长度。** `fc1` 固定为 `Linear(19712, 256)`，要求卷积与池化后的形状为 `[B, 256, 77]`。根据十层无填充卷积及五次池化的尺寸公式推导，兼容输入长度为 **2980–3011**；其中长度 3000 已实际运行通过，区间中的其他长度未逐个实测。
2. **ResNet50 默认按长度 128 配置。** 其 `ModifiedResNet` 使用具有固定位置编码的注意力池化，默认 `input_resolution=128`。长度 512 实测失败；换长度需要使注意力池化的位置编码与实际下采样长度匹配。
3. **返回值不同。** ResNet18/ResNet50 返回 `(feature, logits)`，CNN 与 EfficientNetB0 返回 `logits`。ResNet 的交叉熵应使用返回元组中的第二项。ResNet18 的特征形状为 `[B, 512]`，ResNet50 为 `[B, 1024]`。
4. 分类分数是 logits，没有在网络内进行 softmax；可直接输入交叉熵损失，预测类别可使用 `logits.argmax(dim=1)`。

## EfficientNet 的两个代码问题

- `_make_layers()` 中 `b` 始终为 0，没有递增，因此所有 Block 的 `drop_rate` 都为 0。实测确认 `actual_block_drop_rates=[0.0]`，配置的 drop-connect 未生效。
- `forward()` 将 `F.dropout(feature, ...)` 赋给 `out`，随后执行 `out = self.linear(feature)`，覆盖了该结果。因此配置的分类头 dropout 没有参与最终分类计算。这一项依据源码确定。

## 测试的含义

这些结果证明模型在相应输入尺寸下可以进行分类前向计算与训练更新。使用的是随机模拟数据和新初始化权重，没有训练真实数据集，因此不能据此判断分类准确率或泛化性能。

# 合成辐射源数据难度审计与重训记录

原数据存在明显的参数均值捷径：只使用 CF/PW/PRI 三个均值，不使用脉冲顺序，最近中心分类器即可在验证和测试集获得 100% Macro-F1。原 CNN 的高分不需要复杂时序辨识来解释。

## 固定的实验协议

- 同为 100 类、每类 100 条，训练/验证/测试数量为 7000/1500/1500，类别仍为具体辐射源身份。
- 相同 CNN 结构（64/128/256 通道）、256 输入长度、尾部补零、batch_size=64、lr=0.001、20 个 epoch 上限、相同调度器、相同早停设置和关闭训练增强。
- 数据生成种子保持 2026。三次重训只改变训练随机种子；每次从头训练，不恢复旧权重。
- 新数据设置在训练前固定，未按测试 F1 调参或反复重生成来追求某个目标分数。每次仅用验证 Macro-F1 选择最佳权重，最后评估测试集。
- 三均值分类器的归一化尺度与类别中心只在训练集拟合。
- 新旧数据各自的 train/val/test 都没有共享文件或相同 CSV 内容。内容指纹和生成配置 SHA256 保存于审计 JSON。

## 具体生成变化

1. 100 个辐射源分为 20 组，每组 5 个源。组内共享相同发射机模板和接近的调制幅度，CF/PW/PRI 基础中心的最大相对偏差为 1%、2.5%、1.5%；源的周期、码表和参差档位仍可不同。
2. 每个观测段的 CF/PW/PRI 有持续测量偏差，标准差分别为 2.5%、4%、3%，最大绝对偏差 15%。这种偏差不会被序列平均消除。
3. Gaussian 特征噪声目标 SNR 保持 10–20 dB；AR(1) 相邻脉冲相关系数在 0.4–0.85 之间变化。按各通道能量缩放，修正非物理值之后记录实际 SNR。
4. 每条序列有 5–20% 的目标漏脉冲率，保留首尾端点。删除内部脉冲后，从累计到达时间重新计算 PRI，跨越漏脉冲的间隔等于对应原始间隔之和。
5. 原始长度仍为 128–512；漏脉冲之后当前 CSV 实际长度为 98–492。固定模型长度在 pipeline 中控制。元数据同时记录原始长度和观测长度。

用训练集序列均值的“均值 ± 2 个经验标准差”区间检查，同组 200 对辐射源在 CF/PW/PRI 三个边际区间上均有交集。该指标是边际重叠诊断，不是联合分布完全相同或严格置信区间的证明。

## 建模依据与边界

公开研究将参数重叠、测量误差、漏脉冲及混入脉冲作为雷达识别的实际困难，并指出漏脉冲应改变观测时间间隔。本次采用其中的参数重叠、测量误差和漏脉冲机制；未实现混入脉冲。参考 [Radar Emitter Recognition Based on Spiking Neural Networks](https://www.mdpi.com/2072-4292/16/14/2680) 与 [Turing 数据集官方说明](https://github.com/alan-turing-institute/turing-deinterleaving-challenge)。

这里的参数数值是公开的工程实验设置，并非从实测设备标定得到，也不声称完全复现上述论文或公开数据集。当前是已知源身份的闭集识别：同一个源的不同观测段进入不同划分，不是未知源泛化测试。CF 的调制仍按脉冲编号表示，phase_coded 为频率代理，不是实际脉内相位。物理修正后的噪声不再是无约束高斯噪声。

新设置属于强重叠压力测试。当前 CNN 与均值基线差距较小，需要后续检查更强时序模型、各类不可辨识程度及不同难度档；更低的 F1 不能独立证明真实环境代表性。若作为论文基准，还需公开生成引擎、配置、数据和评估协议，增加公开或实测数据验证。
